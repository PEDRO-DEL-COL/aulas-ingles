# Conta Google obrigatória para alunos

**Regra do projeto:** o login da área do aluno é feito **somente com conta Google**. A professora só libera um aluno cadastrando na ficha (`students.email`) o **e-mail de uma conta Google** dele:

- um endereço Gmail (`fulano@gmail.com`); ou
- uma **Conta Google criada com outro e-mail** que a pessoa já usa (ex.: `fulano@hotmail.com`, `fulano@empresa.com.br`).

O banco não consegue verificar se o e-mail é de uma conta Google; se não for, o aluno simplesmente não conseguirá entrar. Por isso confirme com o aluno antes de cadastrar.

## Como orientar um aluno que não tem conta Google

Texto pronto para enviar pelo WhatsApp (o mesmo conteúdo aparece na tela "Acesso não liberado"):

> Para acessar a área do aluno você precisa de uma conta Google. Se ainda não tiver, dá para criar de graça **usando o e-mail que você já usa**, sem precisar criar um Gmail:
>
> 1. Acesse **accounts.google.com/signup**.
> 2. Preencha nome e data de nascimento.
> 3. Quando pedir o endereço, escolha **"Usar seu endereço de e-mail atual"** e digite o seu e-mail.
> 4. Confirme o código que o Google enviar para esse e-mail e crie uma senha.
> 5. Me mande esse e-mail para eu liberar o seu acesso.
>
> Se preferir, também pode criar um Gmail novo — é só me mandar o endereço.

## Aluno menor de idade

- Menores de 13 anos não podem criar conta Google sozinhos: o responsável cria pelo **Family Link** (<https://families.google/familylink/>) ou o aluno usa uma conta que o responsável administra.
- O responsável **não tem login próprio** nesta fase. O consentimento dele (LGPD, art. 14) é registrado pela professora na ficha do aluno: `consent_by_guardian_at`, `guardian_consent_name` e `guardian_consent_notes`.
